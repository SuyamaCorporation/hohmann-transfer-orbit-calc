# ホーマン遷移軌道 ΔV 計算ツール

2つの円軌道間のホーマン遷移に必要なΔVを計算する宇宙工学入門ツール。

## 機能

- 地球・月・火星・太陽を中心天体として選択可能
- ΔV₁（第1バーン）・ΔV₂（第2バーン）・合計ΔVを計算
- 比推力(Isp)と初期質量からツィオルコフスキー方程式で推進剤質量を算出
- 遷移時間・遷移楕円の半長軸を表示
- LEO→GEO / 地球→月 / 地球→火星等のプリセット対応
- Canvas による軌道図描画（初期軌道・目標軌道・遷移楕円・バーン点）

## 技術メモ

- ΔV₁ = √(μ/r₁)·(√(2r₂/(r₁+r₂)) − 1)
- ΔV₂ = √(μ/r₂)·(1 − √(2r₁/(r₁+r₂)))
- ツィオルコフスキー: ΔV = Isp · g₀ · ln(m₀/mf)
- 単体 HTML + Tailwind CDN、localStorage なし（入力値はページ内のみ）
